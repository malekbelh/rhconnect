# Back-office admin RhConnect

## Prérequis

- Node.js 20+
- npm 10+

## Installation

```bash
cd backoffice-admin
npm install
```

## Démarrage

```bash
npm start
```

## Build

```bash
npm run build
```

## Vue actuelle

Le back-office contient désormais une structure Angular minimale avec une page dashboard et des pages placeholder pour :

- utilisateurs,
- offres,
- candidatures,
- vérifications.
