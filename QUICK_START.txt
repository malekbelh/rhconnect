━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Page blank/not loading
  → Check frontend running: npm run dev in frontend-public/
  → Check backend running: mvn spring-boot:run in backend/
  → Clear browser cache (Ctrl+Shift+Delete)
  → Hard refresh: Ctrl+Shift+R

Problem: Login fails
  → Check backend logs (should show requests)
  → Verify MongoDB running (mongodb://localhost:27017)
  → Try different account
  → Check browser console (F12) for errors

Problem: Dark mode not working
  → Check if toggle is visible in header
  → Clear localStorage: F12 → Console → localStorage.clear()
  → Refresh page

Problem: Images not loading
  → Check network tab (F12 → Network)
  → Verify assets are in public folder
  → Try hard refresh

Problem: Styling looks wrong
  → Check if Tailwind CSS loaded (F12 → Network → check .css files)
  → Try clearing browser cache
  → Check browser compatibility (use Chrome if unsure)
