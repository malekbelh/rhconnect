# Frontend public RhConnect

## Prérequis

- Node.js 20+
- npm 10+

## Installation

```bash
cd frontend-public
npm install
```

## Démarrage

```bash
npm run dev
```

## Build de production

```bash
npm run build
```

## Points d’entrée

- Landing page : `/`
- Connexion : `/auth/login`
- Inscription : `/auth/register`
- Espace candidat : `/candidate/dashboard`
- Espace entreprise : `/company/dashboard`
